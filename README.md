# 重生之研究牲任务系统 V0.3

研究生生活像一场超长副本：科研要推进，课程要应付，工作还得找。待办清单越写越长？那就把现实生活玩成一场 RPG。

**创建任务、完成挑战、积累 XP 和金币，再把努力兑换成游戏时间、奶茶和出门放风。** 这里没有掉队惩罚，只有下一条可以接取的任务。

## 接取你的任务

- **主线任务**：科研、学业、找工，三条人生主线各自推进。
- **支线任务**：LeetCode、自学、运动、午休、洗衣服、早睡早起……生活琐事也值得打个勾。
- **BOSS 挑战**：论文复现、高难度目标，或需要长期坚持的挑战；可以拆成子任务，逐步削减血条。

用总览、任务列表、Kanban 看板和月历安排进度。任务支持标签、筛选、排序、进展记录、完成度反馈和目标清单。任务卡片会显示按 100% 完成度预估的 XP 与金币奖励；新建任务的计划日期默认为今天，截止时间默认为今天 23:59。

目标清单可在新建或编辑任务时逐条编写，也可以在目标悬浮窗中直接添加待办。每个目标在所属任务的进展记录中最多保留一条完成记录：首次完成时记录时间，再次完成时更新这条记录；重新打开目标只会取消勾选，不新增记录，并保留上次完成时间。悬浮窗可在应用内拖动、缩放；加号会打开空白待办编辑行，输入后按 Enter 或离开输入框保存，按 Esc 取消。支持的浏览器可将目标清单置于其他应用上方；不支持时仍可使用应用内悬浮窗。目标窗口只显示任务名称和待办项。模板与任务复制会保留目标内容，但重置勾选状态和完成时间。

任务可从详情复制或保存为模板，也可创建、编辑、删除模板并用模板快速新建。复制会保留任务设定，将计划日期和截止日期设为今天，并清除完成状态和进展记录。Boss 复制或保存为模板时，可选择是否连同子任务一起处理；Boss 模板可编辑子任务，套用时会一并创建。单独复制子任务时，可选择保留原 Boss 归属或复制为独立任务。模板不保存具体日期，但保存截止时刻，套用时日期设为今天。Boss 必须在全部子任务完成后才能完成。

看板默认显示当天所有状态的任务，也可筛选查看其他日期、已完成记录、任务类别和主线分支。日历支持按天记录表情心情。首页“每日任务”入口可直接前往每日候选任务。角色页会展示等级、XP、金币及奖励流水，并支持按奖励类别和本地日期筛选。等级显示上限为 999，超过后显示“999+”，点击可查看实际等级。像素风界面自带可选 8-bit 音效，升级时有专属音效和提示。

## 本月更新（2026-11）

- **复制任务与任务模板**：复用已有任务设置，减少重复填写；模板可创建、编辑、删除，也能从现有任务保存。
- **周期性任务**：支持日常和周常自动生成新任务实例，完成后可按周期继续领取奖励，同时保留历史记录。
- **灵活的每日奖励**：完成带有“日常”或“每日”标签的任务即可累计进度，不必只从候选任务中选择。
- **目标 TO DO**：在任务中拆分具体待办，通过悬浮窗随时查看、勾选和跟进进度。

## XP、金币和现实奖励

完成任务可获得 **XP** 和 **金币**：XP 用于升级，金币用来兑换奖励。新建任务时，系统会按任务类别、稀有度、Boss 挑战和周期给出建议值，你可以直接采用，也可以自行调整。

首次完成时选择完成度：100% 获得标准奖励，0% 不发奖励，奖励倍率最高按 200% 计算。重新打开已完成任务不会退回奖励，再次完成也不会重复领奖。

常驻商店可以放进你想要的现实奖励，例如奶茶、游戏时间、电影或周末出门。商店初始为空，奖励和金币价格由你自己决定。XP 不会被拿去消费。

每天还有独立的 **游戏时间奖励**：当天完成且带有“日常”或“每日”标签的任务，其完成度累计达到 500%，可领取 1 小时游戏时间。每日奖励候选任务会自动带上这两个标签；其他任务添加任一标签后当天完成，也会计入进度。它不扣金币，也不走商店兑换。每日奖励条件、候选模板和奖励规则都可以调整。

## 开始游玩

需要 **Node.js 18 或更高版本**。项目使用原生 HTML、CSS 和 JavaScript，不需要安装第三方依赖，也没有构建步骤。

1. 双击 `start-local.cmd`。
2. 在浏览器打开 `http://127.0.0.1:4317`。
3. 保持启动窗口运行；关闭窗口或按 `Ctrl+C` 即可停止。

推荐使用项目目录模式：任务数据保存在 `data/state.json`，方便备份或搬迁；`data/` 已加入 `.gitignore`，不会被 Git 意外提交。也可以直接打开 `index.html` 使用浏览器本地存储模式，不过那份数据由浏览器保存，不会与项目目录中的 JSON 同步。

## 成就与成长

成就系统内置 121 项成就，覆盖科研 idea、论文阅读与写作、实验，奖学金与课程，简历、实习和求职，成长等级、整活、硬核挑战、坚持性和奖励探索等分类；也能创建自定义成就，并在选图标时预览像素图形。部分成就通过任务标签识别，创建任务时使用对应标签即可累计进度。连续完成天数以本地日历日和已有完成记录计算，展示历史最长纪录，不会因中断施加惩罚。成就定义与门槛集中在 `achievement-rules.js`，属于可调整的初始默认值；等级读取 `reward-rules.js` 中的 XP 等级曲线。
