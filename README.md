# 重生之研究牲任务系统

研究生生活像一场超长副本：科研要推进，课程要应付，工作还得找。待办清单越写越长？那就把现实生活玩成一场 RPG。

**创建任务、完成挑战、积累 XP 和金币，再把努力兑换成游戏时间、奶茶和出门放风。** 这里没有掉队惩罚，只有下一条可以接取的任务。

## 接取你的任务

- **主线任务**：科研、学业、找工，三条人生主线各自推进。
- **支线任务**：LeetCode、自学、运动、午休、洗衣服、早睡早起……生活琐事也值得打个勾。
- **BOSS 挑战**：论文复现、高难度目标，或需要长期坚持的挑战；可以拆成子任务，逐步削减血条。

用总览、任务列表、Kanban 看板和月历安排进度。任务支持标签、筛选、排序、进展记录和完成度反馈；角色页会展示等级、XP、金币及奖励流水。像素风界面自带可选 8-bit 音效，升级时还有专属提示。

## XP、金币和现实奖励

完成任务可获得 **XP** 和 **金币**：XP 用于升级，金币用来兑换奖励。新建任务时，系统会按任务类别、稀有度、Boss 挑战和周期给出建议值，你可以直接采用，也可以自行调整。

首次完成时选择完成度：100% 获得标准奖励，0% 不发奖励，奖励倍率最高按 200% 计算。重新打开已完成任务不会退回奖励，再次完成也不会重复领奖。

常驻商店可以放进你想要的现实奖励，例如奶茶、游戏时间、电影或周末出门。商店初始为空，奖励和金币价格由你自己决定。XP 不会被拿去消费。

每天还有独立的 **游戏时间奖励**：当天候选任务的完成度累计达到 500%，可领取 1 小时游戏时间。它不扣金币，也不走商店兑换。每日奖励条件、候选模板和奖励规则都可以调整。

## 开始游玩

需要 **Node.js 18 或更高版本**。项目使用原生 HTML、CSS 和 JavaScript，不需要安装第三方依赖，也没有构建步骤。

1. 双击 `start-local.cmd`。
2. 在浏览器打开 `http://127.0.0.1:4317`。
3. 保持启动窗口运行；关闭窗口或按 `Ctrl+C` 即可停止。

推荐使用项目目录模式：任务数据保存在 `data/state.json`，方便备份或搬迁；`data/` 已加入 `.gitignore`，不会被 Git 意外提交。也可以直接打开 `index.html` 使用浏览器本地存储模式，不过那份数据由浏览器保存，不会与项目目录中的 JSON 同步。

## 成就与成长

成就系统内置 28 项成就，覆盖科研、学业、求职、编程、自学、生活习惯、BOSS 挑战和奖励探索；也能创建自定义成就。等级阈值、任务奖励、每日奖励和成就规则分别集中在 `reward-rules.js`、`daily-reward-rules.js` 和 `achievement-rules.js` 等文件中，方便按自己的节奏调整。
